## Open Source Devtools (50+)

A collection of zero-config, no-API-key CLI tools for developers. All JavaScript, all practical.

**Favourites:**

- [`repo-report-card`](https://github.com/NickCirv/repo-report-card) — Grade your repo A+ to F across commits, docs, structure, security, CI
- [`secret-scan`](https://github.com/NickCirv/secret-scan) — Pre-commit secret scanner. Catches API keys before they hit GitHub
- [`env-doctor`](https://github.com/NickCirv/env-doctor) — Finds missing vars, empty values, leaked secrets, type mismatches
- [`roast-my-git`](https://github.com/NickCirv/roast-my-git) — Roasts your git habits. Commit frequency, message quality, force-push shame
- [`fix-it-felix`](https://github.com/NickCirv/fix-it-felix) — Self-healing CI pipeline. Diagnoses failures and pushes fixes automatically
- [`ghost-mode`](https://github.com/NickCirv/ghost-mode) — Invisible AI pair programmer. Whispers suggestions only when you need them
- [`repo-whisperer`](https://github.com/NickCirv/repo-whisperer) — Talk to any codebase in plain English. No embeddings, no API key
