## Flagship: engram

[![GitHub stars](https://img.shields.io/github/stars/NickCirv/engram?style=flat&logo=github&label=stars)](https://github.com/NickCirv/engram/stargazers) · [`engramx` on npm](https://www.npmjs.com/package/engramx) · Apache-2.0

Context infrastructure for AI coding tools. Structural code maps and local memory help agents find relevant code and retain lessons across sessions. Local SQLite, no cloud dependency.

One dated run of the project's own harness recorded an 89.1% aggregate token reduction across an 87-file codebase ([result log](https://github.com/NickCirv/engram/blob/main/bench/results/real-world-2026-04-24.md)). Read the [benchmark documentation](https://github.com/NickCirv/engram/blob/main/bench/README.md) before relying on that figure: it states which values are simulated and what each harness does and does not measure.

[Read the project](https://github.com/NickCirv/engram#readme) · [Installation](https://github.com/NickCirv/engram/blob/main/docs/install.html)
