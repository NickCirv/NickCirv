# Recommended profile pins

GitHub allows six pinned repositories. Pins are set by the owner through the GitHub profile UI; this workspace performs no remote changes. engram does not consume a pin slot here because it already occupies the flagship block at the top of the profile README; the elevation plan's cross-cutting guidance permits swapping one slot below for engram if the owner prefers the flagship pinned as well.

| Pin | Rationale |
| --- | --- |
| [engram-counter](https://github.com/NickCirv/engram-counter) | Evidence layer for the flagship: a visitor checking engram's savings figure lands directly on the audit primitive. |
| [cirv-accessibility-index](https://github.com/NickCirv/cirv-accessibility-index) | The compliance data product; anchors the web and accessibility service line with a real dataset. |
| [cursor-to-claude](https://github.com/NickCirv/cursor-to-claude) | Captures the highest-intent switching moment in AI tooling; people searching this migration match the consulting buyer persona. |
| [robots-txt-audit](https://github.com/NickCirv/robots-txt-audit) | Timely AI crawler visibility topic, zero dependencies; quick technical credibility for web work. |
| [dep-doctor](https://github.com/NickCirv/dep-doctor) | One run surfaces a project's dependency risk; a concrete, demo-able Node.js maintenance tool. |
| [wp-plugin-health](https://github.com/NickCirv/wp-plugin-health) | WordPress credibility anchor; sits alongside the four Cirv plugins listed on WordPress.org. |

Before pinning any repository, confirm it shows a working demo or benchmark above its README fold, per the elevation plan. As of this revision that gate has not been re-verified per repository; treat it as the owner's pre-pin checklist.
